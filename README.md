♻️ Automated Waste Segregation System
Using Machine Learning & Robotics

🚀 Overview
This project presents a low-cost automated waste segregation system that combines machine learning, sensors, and robotics to efficiently classify waste into different categories.
The system is designed to reduce manual effort and improve accuracy in waste sorting, making it suitable for smart waste management applications.

💡 Key Features

🧠 Machine Learning Detection
Detects sanitary waste (pads) using image processing with ~90% accuracy
🧲 Metal Detection & Separation
Uses a robotic arm with electromagnet to pick and place metal waste
💧 Wet Waste Identification
Uses a moisture sensor for early-stage wet waste detection
⚙️ Shaker Mechanism
Ensures single-item flow for better detection accuracy

🔄 Automated Sorting Pipeline
Step-by-step waste classification into:
Wet Waste
Sanitary Waste
Metal Waste
General Waste

🏗️ System Workflow
Waste Input → Shaker → Conveyor Belt  
→ Wet Detection → ML Detection → Metal Detection → Final Sorting
